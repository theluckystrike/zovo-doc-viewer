Why open files here

No upload

Online viewers that use Google or Microsoft send your file to their servers first. This one reads it in the page. Open the network tab in your browser tools to check.

Large files

Spreadsheets and CSV files show in a grid that draws only the rows on screen. A million-row CSV scrolls as fast as a short one. Parquet shows the first 100,000 rows and the schema.

Works offline

Once the page has loaded, you can switch off your network and keep opening files. Find, zoom, print and full screen all work without a connection.

Add the viewer to your own site

Zovo Doc Viewer is one custom element. It works in plain HTML, React, Vue, Svelte and any other framework. Each format loads its own code only when a file of that type is opened, so the element itself is about 10 KB gzipped.

<script type="module" src="https://cdn.jsdelivr.net/gh/theluckystrike/zovo-doc-viewer@v0.1.0/dist/zovo-doc-viewer.js"></script>

<zovo-doc-viewer src="/files/report.docx" theme="auto" download="false"></zovo-doc-viewer>

Open a file the user picked, with no server at all:

const viewer = document.querySelector('zovo-doc-viewer');
input.addEventListener('change', () => viewer.load(input.files[0]));
viewer.addEventListener('load', (e) => console.log(e.detail.format, e.detail.pages));
viewer.addEventListener('error', (e) => console.log(e.detail.message));

Attributes: src, theme (light, dark or auto), download="false", print="false", toolbar="false", filename, format, max-size (MB), base-url and license-key. Full reference, React and Vue examples are in the README.

Questions

Is my file uploaded anywhere?

No. The page reads the file with your browser and draws it on your screen. The only network requests are this page, the viewer code and, for the samples, the sample file.

How do I view a DOCX file without Word?

Click "Open a file" above, or drag the DOCX file onto the viewer. You get the pages as Word lays them out, with find and print.

Can I open a Parquet file online without Python?

Yes. Drop the .parquet file on the viewer. You see the rows in a grid and the column types in the Schema tab. Nothing is installed and nothing is uploaded.

Does "download=false" protect my files?

It hides the download button, which is what most sites want. It is not copy protection: anyone who can view a file in a browser can also save it.

Do I need the commercial licence?

Only for closed-source use. If your project is open source under a GPL-compatible licence, or you use the viewer on localhost, it is free. See COMMERCIAL.md.

Which browsers work?

Current Chrome, Edge, Firefox and Safari (16.4 or newer).
